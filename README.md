# AI Academic Performance Report Generator

## Project Overview
The AI Academic Performance Report Generator is a Python-based academic analytics project designed to analyze student performance, identify learning gaps, detect declining academic trends, and highlight students who need additional support.

The system processes student performance data and generates structured academic reports to support data-driven educational decisions.

## Key Features
- Calculates average mastery across Math, Science, and English.
- Measures progress compared with previous mastery.
- Identifies gaps against an 80% mastery target.
- Classifies student performance priorities.
- Detects improving and declining learning trends.
- Identifies high-risk students.
- Generates class-level performance summaries.

## Technologies Used
- Python
- Pandas
- CSV

## Project Files
- `main.py` – Main academic performance analysis program.
- `student_data.csv` – Student performance dataset.

## How to Run

1. Install Python.
2. Install Pandas:

   `pip install pandas`

3. Download or clone this repository.
4. Open the project folder in PowerShell or a terminal.
5. Run:

   `python main.py`
